# Contributing

Welcome! This short guide explains how to contribute effectively to **Athena Algorithms**.

## Submitting an issue

- If you find a bug or mistake in a solution, please submit an issue to our GitHub [repository](https://github.com/saidake/athena-algorithms/issues).
- Before submitting, search the issue tracker to see if your problem already exists.
- Include the problem number, language(s), and enough detail to reproduce or verify the issue.

## Branch Naming Convention

Use lowercase, kebab-case, and a type prefix:

- `feature/<short-title>`
- `bugfix/<short-title>`
- `docs/<short-title>`

**Example**: `docs/add-valid-palindrome`

## Commits

- Keep commits small and focused.
- Prefer this repository's commit style:

```text
type: short summary
```

The summary starts with a lowercase letter (do not capitalize the first word).

**Examples**:

- `feat: add valid palindrome solution`
- `fix: correct time and space complexity analyses`
- `docs: merge category structure into README`

Common types: `feat`, `fix`, `docs`/`doc`, `style`, `refactor`, `chore`, `ci`.

See [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for additional inspiration.

## Pull Requests

1. Fork the repo on GitHub
2. Create a branch from `main`
3. Make the changes and push (see [Commits](#commits))
4. Open a pull request with enough context to review and verify

Thank you for contributing!
